# Cover letter (`cover-letter.txt`)

Plain text, ready to paste into email or application forms.

**Length:** ~250–400 words.

**Structure:**

1. Greeting + role/company
2. Why this company / role (1–2 sentences, specific to the JD)
3. Fit: 2–3 factual strengths mapped to JD must-haves (stack, ownership, metrics)
4. Honest positioning if there is a stretch (years, missing tools) — brief, confident, no fabrication
5. Close + soft ask

**Rules:**

- Same truthfulness as the CV — never invent experience, tools, years, or metrics
- Align tone and keywords with the tailored CV for that folder
- Prefer concrete wins (Example Travel Platform traffic metrics, Angular/React ownership) over generic enthusiasm
- English by default unless the JD or user requests Arabic
