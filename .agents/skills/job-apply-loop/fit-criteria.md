# Fit criteria — Example Candidate (employment sites)

Read `../candidate-source.md` and `resume.tex` before scoring. The criteria below are a routing aid; the current `.tex` remains authoritative.

## CV anchors

- Frontend Developer; +2.5 years of production experience across React and Angular
- Current work: B2B aviation flight search, fare pricing, and booking flows across GDS/LCC suppliers
- Current ownership: MVC → REST/Angular 14+ migration and supplier-specific frontend architecture
- React/Next.js: SSR, PWA, API integration, SEO/rendering, Web Vitals
- Core frontend: TypeScript, JavaScript, HTML/CSS/SCSS, React, Next.js, Angular/AngularJS, RxJS, Redux, Tailwind
- Supporting backend/API: Node.js, Express, REST, WebSockets, MongoDB, MySQL, Redis, JWT
- Location: Remote City

Do not add language level, salary, notice period, availability, work authorization, relocation, or remote preference; none may be inferred from this list.

## Must fit

Prefer roles where the core work includes one or more:

- React, Next.js, or Angular frontend engineering
- TypeScript UI architecture
- REST/API-driven product UI
- B2B SaaS, booking, travel/aviation, pricing, e-commerce, dashboards, or workflow-heavy interfaces
- Legacy frontend migration/refactoring
- SSR/SSG, PWA, Core Web Vitals, performance, or SEO rendering

And all are true:

- The required core stack substantially overlaps the current CV
- Years/seniority do not require unsupported claims
- Location/work mode is explicitly compatible or does not require an unsupported declaration
- The role is active and application route is credible

## Strong fit

- Frontend-heavy full-stack roles where Node/Express/API work is secondary
- Mid-level ownership matching the current Example Travel Platform migration and architecture responsibilities
- Product teams requiring Agile collaboration with backend, QA, and product
- Third-party API integrations and complex state/edge-case handling

## Stretch — show the risk

- Strong frontend match plus one secondary tool absent from the CV
- Senior wording where the actual responsibilities match CV-demonstrated ownership but the stated years do not create a hard mismatch
- Relocation/on-site opportunity with no explicit authorization requirement; ask the user before declaring preference

## Skip silently

- Backend-only, DevOps-only, native mobile, data/ML, QA-only, or design-only roles
- Core requirements centered on unsupported stacks (for example Java/Spring, .NET, PHP/WordPress, Flutter, native iOS/Android)
- Hard 4/5/7+ years requirements when the current CV states +2.5 years
- Required language proficiency, clearance, work authorization, relocation, or degree discipline that the CV does not establish and cannot be answered without the user
- Unpaid work, suspicious identity/payment requests, WhatsApp-only recruiting, wallet/crypto transfers, or unclear employer
- Duplicate, expired, or already-applied roles
