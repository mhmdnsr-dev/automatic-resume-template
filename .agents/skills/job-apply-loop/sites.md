## Referral sourcing and outreach gate

- Treat referrals as an always-on source, not a conventional job board. Use
  user-provided contacts, existing professional relationships, public employee
  referral posts, or official employer referral campaigns.
- Find and score the actual job first, then show the normal Job Card and ask
  **Apply now?** before preparing an application.
- Before contacting any person, show the intended recipient, communication
  channel, and exact draft, then ask: **Send this referral request?**
- Send nothing until the user gives explicit approval for that recipient and
  message. Never imply a relationship or endorsement, scrape private contact
  details, or send bulk referral requests.
- A referral or tracking link that opens a job board or ATS makes that
  destination the active site; rerun the login-page rule.

## Site selection rules

- Prefer direct employer listings and recently posted roles.
- Search Egypt, Cairo, remote, hybrid, and MENA roles only when the JD’s location terms are compatible; do not infer work authorization or willingness to relocate.
- Avoid duplicate listings across sites. Track canonical company + title + URL.
- Aggregators, including JobHunt and Tanqeeb, are discovery only. Verify the
  destination, canonical employer listing, and original posting date; never
  activate an auto-apply or bulk-apply feature.
- Add a new site only if it is reputable, candidate-facing, currently active, and meaningfully used in Egypt/MENA. Record its official URL and role before using it.
- Never downgrade fit standards just to keep a site active.

## Rotation

- Login page → pause for user takeover; if unresolved, mark the site blocked and move down this list without closing tabs.
- Feed exhausted/no strong fit → move down this list.
- One successful submission → ask: **Do we continue with the same site or move to another?**
- If the user chooses another, move to the next non-blocked site; wrap to priority 1 only after every site has been tried.
