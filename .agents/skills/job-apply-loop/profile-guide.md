# Profile fitting guide — employment sites

Read `../candidate-source.md` and `resume.tex` fresh before each site. The `.tex` wins over every existing profile value.

## Positioning

Use concise CV-supported wording:

- **Headline:** `Frontend Developer | React, Angular & Next.js`
- **Current title:** `Mid-Level Frontend Developer` only where a current-role title is requested
- **Location:** `Remote City`
- **Industry/category:** Software Development / Information Technology / Web Development / Frontend Development — select the closest site taxonomy, not a fabricated title

## About / summary

Build the summary from the current CV’s Professional Summary and strongest matching experience. Keep these facts traceable:

- +2.5 years production experience across React and Angular
- B2B aviation flight search, fare pricing, and booking workflows across GDS/LCC suppliers
- MVC to REST/Angular 14+ migration ownership
- React/Next.js applications with SSR and PWA features
- UI architecture, third-party API integration, Agile delivery, and AI-assisted engineering tools listed in the CV

Do not introduce personality claims, language fluency, availability, desired salary, remote preference, relocation, visa/work authorization, or years beyond the exact CV statement.

## Experience

Mirror each CV role exactly:

1. Example Travel Platform, Remote City — Jun 2024–Present
   - Mid-Level Frontend Developer — Feb 2026–Present
   - Junior Frontend Developer — Jun 2024–Feb 2026
2. Freelance Frontend Developer / Independent Web & Desktop Projects — Nov 2023–Jun 2024

Use CV bullets selectively according to field limits. Preserve dates, employer names, role progression, links, and metrics exactly.

## Education

- Example Training Program — Intensive Code Camp, Full Stack MEARN — Jun 2023–Nov 2023
- Example University — B.Sc. in Biology — Oct 2015–Jun 2020

Do not recast Example Training Program as a degree or the Biology degree as Computer Science.

## Skills

Rank platform skill tags by target relevance while selecting only technologies present in the current CV. Default frontend order:

React, Angular, TypeScript, Next.js, JavaScript, RxJS, REST APIs, HTML5, CSS3, Tailwind CSS, Redux, PWA, SSR/SSG, Web Vitals, Node.js, Express, Git/GitHub, Azure DevOps, Agile/Scrum.

Respect platform caps; do not add a tag solely for search ranking.

## Projects and links

Use only links present in the `.tex`: LinkedIn, GitHub, example-booking.com, example-games.com, example-shop.com, example-writer.app, ADO Work Companion GitHub/live, Event Booking Platform GitHub/live.

Confirm a site permits external links before adding them.

## Required unknown fields

Pause and ask the user if the site requires any CV-absent data, including:

- expected/current salary
- notice period / start date / weekly availability
- language proficiency
- work authorization / visa / nationality where not legally required and user-provided
- willingness to relocate or preferred work mode
- marital status, military status, date of birth, gender, or other demographic data
- profile photo choice

Never copy these from another profile as if the CV confirmed them.

## Save verification

After save, snapshot/re-open and verify headline, summary, experience dates, education, skills, and links. Log every field changed and any field left untouched because it was not in the CV.
