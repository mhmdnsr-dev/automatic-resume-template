- **Positioning:** Frontend Developer — React, Next.js, Angular
- **Experience:** +2.5 years; Example Travel Platform (Example Travel Platform) Jun 2024–Present; Freelance Nov 2023–Jun 2024

The Arabic proposal default is a platform-writing choice, not a claim about language proficiency. Do not state a proficiency level unless the `.tex` or user provides it.

## Must fit (prefer)

Project clearly needs **one or more** of:

- React و/أو Next.js
- Angular
- TypeScript frontend
- لوحات تحكم / متاجر / حجوزات / SaaS واجهات
- تحسين أداء / SSR / PWA
- تكامل REST APIs مع واجهة

And:

- Budget not absurdly below market for the stated scope
- Skills overlap ≥ ~50% with profile
- Scope is frontend-deliverable by one mid-level freelancer

## Strong fit

- Frontend-heavy with light backend mention
- «فول ستاك» but description is mostly UI (React/Angular)
- تحويل / تحديث واجهة قديمة → حديثة (Angular أو Next)

## Stretch (ask with risk)

- Strong UI job + one tool not on CV (disclose honestly; never claim it)
- Slightly senior wording if tasks match Example Travel Platform ownership already done

## Skip (do not ask — find next)

- Backend-only / DevOps / تطبيقات موبايل أصلية / تصميم فقط بدون تنفيذ
- WordPress / PHP فقط بدون مسار React/Angular
- مشاريع تتطلب تفضيل عمل/انتقال/تصريحًا غير مثبت في السيرة؛ اسأل المستخدم عند الحاجة
- متطلبات سنوات/تقنية غير موجودة لديك
- إشارات نصب: عمل مجاني «اختبار»، تحويل خارج المنصة أولًا
- سبق التقديم عليه في هذه الجلسة
