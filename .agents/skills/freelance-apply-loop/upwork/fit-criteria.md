# Fit criteria — Example Candidate (Upwork)

Score each job before asking **Apply now?**

Read [`../../candidate-source.md`](../../candidate-source.md) and `resume.tex` fresh before scoring. The current `.tex` wins if this guide becomes stale.

## CV anchors

- **Title focus:** Frontend Developer — React, Next.js, Angular; B2B booking UIs
- **Experience:** +2.5 years production; Example Travel Platform (Example Travel Platform) Jun 2024–Present; Freelance Nov 2023–Jun 2024
- **Strengths:** Flight search / fare / booking flows; GDS/LCC; Angular migration (MVC → REST/Angular 14+); Next.js SSR/PWA; Web Vitals; REST APIs; TypeScript; RxJS; Redux; Tailwind
- **Also true:** Node.js / MongoDB from MEARN + freelance full-stack touches — secondary, not primary pitch
- **Location:** Remote City

Salary/rate, availability, language proficiency, work authorization, relocation, and preferred work mode are not established here. Ask the user if required.

## Must fit (prefer these)

Job clearly needs **one or more** of:

- React and/or Next.js frontend
- Angular frontend
- TypeScript UI work
- Booking / e-commerce / dashboard / B2B SaaS UI
- SSR, PWA, performance / Web Vitals
- REST API–driven SPA work

And:

- Hourly or fixed budget that is sensible for the scope; ask the user before committing to a rate
- Skills overlap ≥ ~50% with profile stack

## Strong fit

- Frontend-heavy with secondary Node/API mention
- “Full stack” but description is mostly React/Angular UI
- Migration / refactor / legacy → modern frontend (Angular or Next)

## Stretch (ask Apply now? with risk called out)

- Strong UI job plus one tool not on CV (say so honestly in proposal; do not claim it)
- Slightly higher seniority wording if tasks match mid-level ownership already done at Example Travel Platform

## Skip (do not ask — find next)

- Pure backend / DevOps / mobile-native / data science / design-only with no frontend implementation
- WordPress / PHP / Shopify theme-only when no React/Angular path
- Requires a work mode, location commitment, authorization, or relocation preference not established by the CV
- Requires claimed years/stack you do not have (e.g. 5+ years Angular + Java Spring as core)
- Scam signals: unpaid “test project”, crypto wallet, off-platform payment first
- Already applied / invited declined this session

## Search hints (when feed is weak)

Try queries like: `React`, `Next.js`, `Angular`, `TypeScript frontend`, `React dashboard`, `booking UI`.

Filter: Hourly or Fixed; Entry–Intermediate preferred; avoid Expert-only unless description matches Example Travel Platform ownership.
